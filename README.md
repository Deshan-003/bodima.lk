# Bodima.lk

Frontend for a Sri Lankan boarding marketplace, built from design mockups.

## Stack

Vite, React 18, TypeScript, Tailwind CSS, React Router, Lucide icons.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:5173.

## Pages

- `/` — landing page with hero, search, features, locations and footer
- `/browse` — searchable listings with filters, sorting and pagination
- `/browse/:id` — property details with photo gallery and booking card

## Assets

Photos in `public/assets/` were extracted from the reference mockups in
`reference/`. The scripts in `scripts/` show how each crop was produced.
